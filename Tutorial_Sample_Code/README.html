SAP Crystal Reports 2010 .NET SDK

  • This zip file contains all the sample code for the tutorials in the SAP Crystal Reports 2010 .NET Developer Guide. This sample code demonstrates some basic applications of the SAP Crystal Reports 2010 .NET SDK.

  • This sample code in this suite uses a variety of sample reports generated from several different sources:
    • The Northwind database is a sample database provided by Microsoft and is available through the MSDN website.
    • The samples in this suite assume deployment to a Microsoft SQL Server, but any secure SQL-capable database will work as well.
    • The Xtreme database is packaged with this zip file, or available online from http://www.sdn.sap.com/irj/boc/downloads.
    • To set up the ODBC connection to the xtreme.mdb database:
      1. In Control Panel, select Administrative Tools.
      2. Select Data Sources (ODBC).
      3. Select the tab System DSN.
      4. Click Add.
      5. Select Microsoft Access Driver (*.mdb) then click Finish
      6. Set the Data Source Name to "Xtreme Database".
      7. Click Select and browse for the xtreme.mdb file on your computer.
      8. Click OK.

  • For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
