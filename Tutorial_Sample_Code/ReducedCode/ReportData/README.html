SAP Crystal Reports 2010 .NET SDK
Reduced-Code Exposing Report Data to Other Controls in a Web Site

  1. This zip file contains all the sample code for the "Reduced-Code Exposing Report Data to Other Controls in a Web Site" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to expose Crystal report data from the CrystalReportViewer control to a label control.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: World Sales Report.rpt
    • This report is bundled as a sample report with most installations of SAP Crystal Reports and is included within the bundled solutions for this tutorial. No additional setup is required.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
