SAP Crystal Reports 2010 .NET SDK
Reduced-Code Secure Database Logon in a Web Site

  1. This zip file contains all the sample code for the "Reduced-Code Secure Database Logon in a Web Site" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to display a report that contains information from a secure SQL Server database by using the new tag-based application development model to connect the key components:
    • Connect a CrystalReportViewer control to a CrystalReportSource control.
    • Connect the CrystalReportViewer control to a report.
    • Connect the report's DataSources property to an SqlDataSource control.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: NorthwindCustomers.rpt
    • This sample report uses the Northwind database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
