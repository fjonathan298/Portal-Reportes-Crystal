SAP Crystal Reports 2010 .NET SDK
Reduced-Code Web Site Setup with Crystal Reports Using Smart Tasks

  1. This zip file contains all the sample code for the "Reduced-Code Web Site Setup with Crystal Reports Using Smart Tasks" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to create an ASP .NET Web Site in Visual Studio, add a CrystalReportViewer control to the Web Form, and use the Smart Task panel to create a CrystalReportSource control and build a Crystal report. The report is referenced within the CrystalReportSource control.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: XtremeCustomers.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
