Crystal Reports 2008 .NET SDK
スマート タスクを使用した Crystal Reports での減少したコードによる Web サイトの設定

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「スマート タスクを使用した Crystal Reports での減少したコードによる Web サイトの設定」のすべてのサンプル コードが含まれています。このサンプル コードは、Visual Studio で ASP .NET Web サイトを作成する方法、CrystalReportViewer コントロールを Web フォームに追加する方法、Smart Task パネルを使用して CrystalReportSource コントロールを作成し、Crystal レポートを構築する方法を示しています。レポートは、CrystalReportSource コントロール内で参照されます。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、XTremeCustomers.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このレポートおよび Xtreme サンプル データベースは、以下からダウンロードすることができます。 http://www.businessobjects.com/product/catalog/crystalreports/samplereports.asp .

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
