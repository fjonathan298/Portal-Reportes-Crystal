SAP Crystal Reports 2010 .NET SDK
Reduced-Code Windows Project Setup with Crystal Reports Using Smart Tasks

  1. This zip file contains all the sample code for the "Reduced-Code Windows Project Setup with Crystal Reports Using Smart Tasks" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to create a Windows project in Crystal Reports for Visual Studio, add a CrystalReportViewer control to the Windows Form, and use the Smart Task panel to create a new Crystal report. The Smart Tasks feature generates code that binds the report to the CrystalReportViewer control.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: XtremeCustomers.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
