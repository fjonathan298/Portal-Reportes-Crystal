Crystal Reports 2008 .NET SDK
スマート タスクを使用した Crystal Reports での減少したコードによる Windows プロジェクトの設定

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「スマート タスクを使用した Crystal Reports での減少したコードによる Windows プロジェクトの設定」のすべてのサンプル コードが含まれています。このサンプル コードは、Crystal Reports for Visual Studio で Windows プロジェクトを作成する方法、CrystalReportViewer コントロールを Windows フォームに追加する方法、Smart Task パネルを使用して新しい Crystal レポートを作成する方法を示しています。スマート タスク機能は、CrystalReportViewer コントロールにレポートをバインドするコードを生成します。
  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、XTremeCustomers.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このレポートおよび Xtreme サンプル データベースは、以下からダウンロードすることができます。 http://www.businessobjects.com/product/catalog/crystalreports/samplereports.asp .

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
