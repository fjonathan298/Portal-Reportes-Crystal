Crystal Reports 2008 .NET SDK
Web サイトでの減少したコードによるセキュリティで保護されたデータベース ログオン

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「Web サイトでの減少したコードによるセキュリティで保護されたデータベース ログオン」のすべてのサンプル コードが含まれています。このサンプル コードは、新しいタグベースのアプリケーション開発モデルを使用して重要な構成要素を接続し、セキュリティで保護された SQL Server データベースの情報を含むレポートを表示する方法を示しています。
    • CrystalReportViewer コントロールを CrystalReportSource コントロールに接続します。
    • CrystalReportViewer コントロールをレポートに接続します。
    • レポートの DataSources プロパティを SqlDataSource コントロールに接続します。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、XtremeCustomers.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このレポートおよび Xtreme サンプル データベースは、以下からダウンロードすることができます。 http://www.businessobjects.com/product/catalog/crystalreports/samplereports.asp .

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
