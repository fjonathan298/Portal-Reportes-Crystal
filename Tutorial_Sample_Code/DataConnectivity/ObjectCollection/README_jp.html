Crystal Reports 2008 .NET SDK
オブジェクト コレクションへの接続

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「オブジェクト コレクションへの接続」のサンプル コードがすべて含まれています。このサンプル コードは、オブジェクト コレクションの各オブジェクト タイプとなるクラスを作成する方法を示しています。このクラスは、株式（Stock）市場の情報を表します。このクラスには、データベース テーブルと同様にレポート ウィザードからアクセスします。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • StockObjects.rpt

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
