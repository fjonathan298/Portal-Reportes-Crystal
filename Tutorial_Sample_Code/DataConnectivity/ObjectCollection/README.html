SAP Crystal Reports 2010 .NET SDK
Connecting to Object Collections

  1. This zip file contains all the sample code for the "Connecting to Object Collections" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to create a class that is the type for each object in the object collection. The class will represent stock market information, which is accessed from the report wizard much like a database table.

  2. This sample code uses the following custom sample report included in the solution file:
    • The required sample report is: StockObjects.rpt

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary.
