SAP Crystal Reports 2010 .NET SDK
Connecting to IDataReader

  1. This zip file contains all the sample code for the "Connecting to IDataReader" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to connect a Crystal report to the DLL assembly file, and how to access a class and static method within the assembly that returns the IDataReader.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: CustomersVialDR.rpt
    • This sample report uses the Northwind database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary.
