Crystal Reports 2008 .NET SDK
選択式を使用したフィルタ

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「選択式を使用したフィルタ」のサンプル コードがすべて含まれています。このサンプル コードは、顧客レコードをフィルタする選択式を作成する方法を示しています。ここでは、“前年度取引高”フィールドが指定値よりも大きいものが選択され、“顧客名”フィールドが別の文字列と比較されます。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、NorthwindCustomers.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このサンプル レポートでは、Northwind データベースがデータ ソースとして使用されます。このサンプル レポートを使用するには、SQL Server または MSDE で提供されている Northwind サンプル データベースをインストールする必要があります。

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
