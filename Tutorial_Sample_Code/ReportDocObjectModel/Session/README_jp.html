Crystal Reports 2008 .NET SDK
Session を使った ReportDocument オブジェクト モデルの永続

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「Session を使った ReportDocument オブジェクト モデルの永続」のサンプル コードがすべて含まれています。このサンプル コードは、ReportDocument オブジェクト モデルを使用して、実行時にプログラムからレポートに変更を加える方法を示しています。また、Session を使用して Web ページの再ロード時にこれらの変更を永続化する方法も示しています。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、Hierarchical Grouping.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このレポートおよび Xtreme サンプル データベースは、以下からダウンロードすることができます。 http://www.businessobjects.com/product/catalog/crystalreports/samplereports.asp .

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
