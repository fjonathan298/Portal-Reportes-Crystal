SAP Crystal Reports 2010 .NET SDK
Persisting the ReportDocument Object Model Using Session

  1. This zip file contains all the sample code for the "Persisting the ReportDocument Object Model Using Session" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to use the ReportDocument object model and make programmatic changes to a report at runtime. It also demonstrates how to use Session to persist those changes across Web page reloads.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: Hierarchical Grouping.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
