Crystal Reports 2008 .NET SDK
CrystalReportPartsViewer コントロールを使ったレポート パーツの表示

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「CrystalReportPartsViewer コントロールを使ったレポート パーツの表示」のサンプル コードがすべて含まれています。このサンプル コードは、レポートをパーツに分割し、一連のハイパーリンクをクリックすることによって各パーツを表示する方法を示しています。ハイパーリンクによって、全体のレポート集計グループから詳細なレポート情報に移動します。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、Customers.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このレポートおよび Xtreme サンプル データベースは、以下からダウンロードすることができます。 http://www.businessobjects.com/product/catalog/crystalreports/samplereports.asp .

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
