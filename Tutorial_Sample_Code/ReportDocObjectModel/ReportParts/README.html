SAP Crystal Reports 2010 .NET SDK
Displaying Report Parts with the CrystalReportPartsViewer Control

  1. This zip file contains all the sample code for the "Displaying Report Parts with the CrystalReportPartsViewer Control" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to break a report into parts and display each part by clicking through a series of successive hyperlinks. The hyperlinks move from a general report summary group to increasingly detailed report information.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: Customers.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
