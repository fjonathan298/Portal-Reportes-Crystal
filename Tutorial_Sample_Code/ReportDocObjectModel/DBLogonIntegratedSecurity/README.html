SAP Crystal Reports 2010 .NET SDK
Logging onto a Secure SQL Server Database Using Integrated Security

  1. This zip file contains all the sample code for the "Logging onto a Secure SQL Server Database Using Integrated Security" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to log onto a Secure SQL Server Database Using Integrated Security by using classes from the ReportDocument object model.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: NorthwindCustomers.rpt
    • This sample report uses the Northwind database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
