SAP Crystal Reports 2010 .NET SDK
Exporting to Multiple Formats

  1. This zip file contains all the sample code for the "Exporting to Multiple Formats" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to export the report programmatically.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: Hierarchical Grouping.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
