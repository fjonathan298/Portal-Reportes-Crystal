SAP Crystal Reports 2010 .NET SDK
Creating a User Function Library

  1. This zip file contains all the sample code for the "Creating a User Function Library" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to create a User Function Library that can be accessed from the Formulas Expert in the embedded Crystal Report Designer.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: FunctionTest.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.
  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary.
