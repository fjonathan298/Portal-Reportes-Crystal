SAP Crystal Reports 2010 .NET SDK
Configuring Multilingual Client Support

  1. This zip file contains all the sample code for the "Configuring Multilingual Client Support" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates the following:
    • How to configure the CrystalReportViewer control language resources on the Windows client or Web server.
    • How to configure client access to localization in various ways.
    • How to configure global or local settings.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: Hierarchical Grouping.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
