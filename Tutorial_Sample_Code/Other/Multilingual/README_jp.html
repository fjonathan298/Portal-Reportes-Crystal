Crystal Reports 2008 .NET SDK
マルチリンガル クライアント サポートの設定

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「マルチリンガル クライアント サポートの設定」のサンプル コードがすべて含まれています。このサンプル コードは、次の操作の実行方法を示しています。
    • Windows クライアントまたは Web サーバーで CrystalReportViewer コントロールの言語リソースを設定する方法
    • クライアント アクセスを設定してロケール設定を行うさまざまな方法
    • グローバル設定またはローカル設定を構成する方法

    • 必要なサンプル レポートは、Hierarchical Grouping.rpt です。
