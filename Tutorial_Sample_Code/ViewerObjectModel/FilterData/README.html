SAP Crystal Reports 2010 .NET SDK
Filtering Data Using Selection Formulas

  1. This zip file contains all the sample code for the "Filtering Data Using Selection Formulas" tutorial in the SAP Crystal Reports 2010 .NET SDK. This sample code demonstrates how to create a selection formula to filter customer records according to a critera, and to compare the Customer Name field to another string.

  2. This sample code uses the following sample report included in the solution file.
    • The required sample report is: CustomersBySalesName.rpt
    • This sample report uses the Xtreme database as a datasource. For configuration details, please see the readme at the root of this tutorial suite.

  3. For additional developer information and resources, visit http://www.sdn.sap.com/irj/boc/sdklibrary
