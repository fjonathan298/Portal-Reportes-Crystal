Crystal Reports 2008 .NET SDK
選択式を使用したフィルタ

  1. この ZIP ファイルには、Crystal Reports 2008 .NET SDK のチュートリアル「選択式を使用したフィルタ」のサンプル コードがすべて含まれています。このサンプル コードは、条件に従って顧客レコードをフィルタする選択式を作成する方法、および“顧客名”フィールドと他の文字列を比較する方法を示しています。

  2. このサンプル コードでは、ソリューション ファイルに含まれている以下のサンプル レポートが使用されます。
    • 必要なサンプル レポートは、CustomersBySalesName.rpt です。
    • このレポートは以下からダウンロードすることができます。
    • このレポートおよび Xtreme サンプル データベースは、以下からダウンロードすることができます。 http://www.businessobjects.com/product/catalog/crystalreports/samplereports.asp .

  3. 開発者向けの追加情報およびリソースについては、http://devlibrary.businessobjects.com を参照してください。
